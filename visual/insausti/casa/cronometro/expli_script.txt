function formatearTiempo(totalSegundos) {
  const hrs = String(Math.floor(totalSegundos / 3600)).padStart(2, '0');
  const mins = String(Math.floor((totalSegundos % 3600) / 60)).padStart(2, '0');
  const segs = String(totalSegundos % 60).padStart(2, '0');
  return `${hrs}:${mins}:${segs}`;
}

- function formatearTiempo(totalSegundos)
 1. const hrs = String(Math.floor(totalSegundos / 3600)).padStart(2, '0');
  - totalSegundos / 3600: Divide los segundos entre 3600 (porque 1 hora = 3600 segundos).
  - Math.floor(...): Quita los decimales para quedarse solo con las horas enteras.
  - String(...): Convierte el número a texto.
  - .padStart(2, '0'): Asegura que tenga 2 dígitos añadiendo un '0' a la izquierda si solo es uno.

 2. const mins = String(Math.floor((totalSegundos % 3600) / 60)).padStart(2, '0');
  - totalSegundos % 3600: Divide entre los segundos que tiene una hora. Coge el modulo de la division ya
    ya que las horas no nos interesan. Se queda con lo que no llega a formar una hora. 
  - / 60: Divide ese sobrante entre 60 para saber cuántos minutos completos hay.
  - Math.floor(...): Elimina decimales para dejar los minutos, sin segundos.
  - String(...).padStart(2, '0'): Le aplica formato de 2 dígitos.

 3. const segs = String(totalSegundos % 60).padStart(2, '0');
  - totalSegundos % 60: Extrae el resto final tras quitar todos los minutos completos.
  - String(...).padStart(2, '0'): Le aplica formato de 2 dígitos.

 4. return `${hrs}:${mins}:${segs}`;
 Une las tres variables guardadas usando un template literal separado por dos puntos. 00:00:00

 * totalSegundos es una variable temporal, se crea y se destruye con la funcion. El valor lo
  lo recive cuando se le llama: totalSegundos(segundosTranscurridos). *
